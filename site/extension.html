这学期十几门课都在学习通上留作业，每次想知道「还有哪些没交」，就得打开手机 App，一门课一门课点进去看；用电脑版网页也一样，得先进入每门课的课程空间，再找作业列表，翻半天才把所有科目过一遍。考试更是藏得深，有的课考试入口在通知里才看得到。

实在受不了，就抽空写了个浏览器扩展，叫「学习通作业聚合」。它只做一件事：把当学期所有课程的作业和考试拉到一个页面里，按课程分组，点一下直接打开电脑版作答页。

Edge 商店地址：https://microsoftedge.microsoft.com/addons/detail/ocagfglinciobakiaicbfnnnfpffhnmb

一、它能干什么

安装后点浏览器工具栏的扩展图标，会在新标签页打开一个聚合面板，效果如下：

  • 全课程作业聚合：一次拉取当学期所有课程的作业列表，按课程分组，显示每门课的条目数，一眼看清哪些还没做。
  • 电脑版直达：点击作业直接打开 mooc2 的电脑版作答页。个别作业在电脑版集合页里找不到对应链接，会自动回退到手机版作答页，保证能打开。
  • 过滤：可以勾选「仅看未完成」「仅看可提交」快速筛选；已经过期的作业会自动标出来，避免误点。
  • 考试：单独一个「考试」标签页。已完成的考试可以直达电脑版查看试卷；还没交卷的只打开该课程的考试列表页，进去之后的考试码、验证码、人脸识别这些流程还是走学习通自己的，扩展不碰。
  • 刷新：交完一项回到面板点一下「刷新」，状态立刻更新。

再强调一下边界：这个扩展只做导航聚合，不代答、不代交、不改学习进度。打开的都还是学习通官方页面。

二、怎么用

三步：

  1. 从 Edge 附加组件商店（或者 Chrome 商店搜同名）安装，点「获取」；
  2. 登录学习通。两种方式都行：先在浏览器里打开学习通网页版登录（账号密码、扫码均可），扩展直接复用这个登录态；也可以在扩展面板里登录，勾选「记住并自动登录」的话，凭据会用 AES-GCM 加密后只存在本机，不上传；
  3. 点工具栏图标，新标签页里点「刷新」，所有课程的作业/考试就都出来了。

如果打开作业提示「未登录」，先手动访问一次 https://mooc2-ans.chaoxing.com/visit/interaction，确认网页版登录态生效，再回来刷新即可。

三、权限说明

写扩展我比较在意权限能少则少，清单里没有申请 tabs、storage、cookies 这些敏感权限，host 权限只有两条：

  • https://*.chaoxing.com/*：读取你自己的作业/考试列表、完成登录。之所以用通配子域，是因为登录、作业、考试接口散在 passport2、mooc2-ans 等好几个子域上，打开链接时还会 302 跳转，写死单个主机根本不够用。
  • https://ssl.dagongren.tech/event：匿名使用统计（只含事件名和扩展版本号，比如 {"event":"feature_used","version":"1.1.18","feature":"fetch_works"}），首次打开时点「同意并继续」才会发，不同意就不发。

不会做的事：不读非学习通域的页面；作业内容、课程名、账号密码不发给作者服务器；不在后台常驻。完整的隐私政策见这里。

四、常见问题

支持哪些浏览器？ Manifest V3 标准扩展，Edge / Chrome 以及其他 Chromium 内核（360 极速、QQ 浏览器之类）都能装。Firefox 因为 MV3 实现有差异，没有做兼容。

会影响账号安全吗？ 扩展只在学习通官方域内用浏览器自动携带 cookie 的方式调接口，跟你自己在浏览器里点没有区别。可以只在网页版登录、让扩展复用登录态，这样它根本接触不到密码。本扩展是个人作品，非学习通官方出品，与超星集团无关。

怎么更新？ 商店渠道自动更新；想本地调试的话，在 chrome://extensions 开「开发者模式」加载解压后的文件夹即可。
