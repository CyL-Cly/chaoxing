它能做什么

专为学习通电脑用户设计，把分散在各门课程里的作业和考试统一拉到眼前。

全课程聚合

一次性把当学期所有课程的作业列表拉过来，按课程归组、显示条目数量，一眼看清哪些还没做。

电脑版直达

点击作业直接打开 mooc2 电脑版作答页，遇到没有电脑版的会自动回退到手机版，绝不让你卡死。

智能过滤

勾选「仅看未完成」或「仅看可提交」快速聚焦重点；自动标记已过期作业，避免误点。

考试也支持

除作业外另开「考试」标签页。已完成的可直达电脑版查看试卷；未交卷的只打开课程考试列表，由学习通自己处理进入考试（考试码 / 验证码 / 人脸），扩展不代答、不代交。

实时刷新

提交完一项回到面板点一下「刷新」，已完成的作业立刻归位、状态从「未提交」变绿。

本地优先

作业、课程与账号信息不上传到作者服务器。匿名使用统计仅含事件名和版本号，首次打开须点同意并继续，不同意则无法使用，详见隐私政策。

三步上手

从安装到第一次打开电脑版作业，整个流程不超过一分钟。

1

安装扩展

从 Edge / Chrome 浏览器附加组件商店搜索「学习通作业聚合」，点「获取」一键安装。

2

登录学习通

可在扩展面板内登录，也可先打开学习通网页版（账号密码 / 扫码均可）。面板登录若勾选「记住」，凭据只加密存在本机。

3

点击工具栏图标

点浏览器右上角的扩展图标，会在新标签页打开聚合面板，刷新即可拉取当学期所有作业 / 考试。

权限透明

未申请 tabs / storage / cookies 权限；host 权限只用于学习通功能与匿名使用统计。

申请的权限说明

清单里没有 tabs / storage / cookies。工具栏点击时，service worker 只用浏览器给扩展自身页面的能力开关本扩展的标签，不会读取你的其他网页。作业缓存、界面偏好、统计同意都写在扩展页本地存储里。

https://*.chaoxing.com/* · 读取你本人的作业 / 考试列表，并在该域完成登录。登录、作业、考试接口分布在多个子域，打开链接时还可能 302，所以使用通配子域而不是写死单个主机。

https://ssl.dagongren.tech/event · 匿名使用统计上报（事件名 + 扩展版本）。首次打开点同意并继续后才发送；不同意则不发送且无法使用。

不会做的事：不读取非学习通域的页面、不把作业内容 / 课程名 / 账号密码发给作者服务器、不代答或代交、不在后台长期驻留运行。完整说明见隐私政策。

常见问题

如果你遇到了其他问题，欢迎通过商店页面的反馈渠道联系作者。

支持哪些浏览器？
Manifest V3 标准扩展，Edge / Chrome / 其他 Chromium 内核浏览器（如 360 极速、QQ 浏览器等）均可安装使用。Firefox 因 MV3 实现差异暂未保证兼容。
打开作业后提示「未登录」怎么办？
请先在浏览器里手动打开 https://mooc2-ans.chaoxing.com/visit/interaction 等学习通页面，确保登录态生效，再回到聚合面板点「刷新」即可。
有些作业显示「手机版」是正常的吗？
是的。少数作业在电脑版集合页里找不到对应链接，扩展会自动回退到手机版作答页，避免打不开。其他大部分作业都会优先电脑版直达。
会影响学习通账号安全吗？
扩展只在学习通官方域内用浏览器自动携带 cookie 的方式调用页面接口，等同于你自己在浏览器里操作，不会修改账号信息。你可以先在网页版登录，扩展只复用该登录态、不接触密码。可选的「记住并自动登录」会把凭据加密存在本机 IndexedDB，不会上传到作者服务器；匿名使用统计不含账号、课程或作业内容。本扩展非学习通官方，与超星集团无关。
更新方式？
商店渠道会自动更新；也可以在 chrome://extensions 开启「开发者模式」后手动加载解压后的文件夹进行本地调试。
