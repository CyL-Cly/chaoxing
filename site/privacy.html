隐私政策

适用于「学习通作业聚合」浏览器扩展。最近更新与当前版本一致。

收集范围

首次打开扩展时，须在欢迎页点「同意并继续」后，才会向作者服务器 https://ssl.dagongren.tech/event 发送匿名使用事件；点「不同意」则不发送。JSON 载荷只有：

{"event":"feature_used","version":"<扩展版本>","feature":"app_open"} 或 {"event":"error","version":"<扩展版本>","error":"login_failed"}。

feature 枚举：app_open、login、fetch_works、fetch_exams、open_work、open_exam、refresh、hide_item、restore_item。error 枚举：login_failed / need_login / request_failed。

JSON 不含手机号、密码、课程名、作业标题、答卷内容、页面 URL，也不写入 install_id 或其他持久客户端 ID。HTTPS 连接本身仍会让服务器看到你的 IP、User-Agent 和扩展页 Origin，这些不在 JSON 里，也无法从本机关掉。

用途

了解功能使用量和登录 / 请求失败情况，便于排错和判断哪些功能值得保留。统计数据不用于广告、画像或向第三方出售。

留存期限

服务端匿名事件保留最多 18 个月，之后删除或只保留聚合计数。本机同意状态写在扩展页 localStorage，卸载扩展或清除该站点数据后即消失。

撤回方式

欢迎页点「同意并继续」后不再提示；点「不同意」则不发送匿名事件，且无法使用扩展，下次打开仍须同意。已同意后可清除扩展页站点数据或卸载扩展。因为没有用户标识，已经发出的匿名事件无法按人删除。

第三方接收方

ssl.dagongren.tech 是作者用于接收上述匿名事件的端点，仅此用途。本站 refree.rth1.xyz 只托管落地页和本隐私政策，不接收扩展上报。作业、考试、登录请求只发给 *.chaoxing.com。

扩展内「留言反馈」会打开金山文档表单 f.wps.cn。那是你主动点击后的导航，扩展不会自动向金山发送数据；该表单受金山自己的隐私政策约束。

本机保存的登录凭据与课程缓存

你可以只复用浏览器里已有的学习通登录态，不必在扩展里输入密码。若选择在扩展内登录并勾选「记住并自动登录」，手机号和密码用 AES-GCM 加密写入本机 IndexedDB，密钥标记为不可导出。这只能避免明文落盘，不能防止同源脚本解密——扩展没有第二把用户密钥。凭据只用于向 passport2.chaoxing.com/fanyalogin 提交，不会进入统计通道。不勾选则不保存。旧版曾把明文写在 localStorage，当前版本读取后会立刻删除该明文键。

作业 / 考试标题、课程名、截止时间和打开用的链接会缓存在本机扩展页 localStorage，方便下次秒开；这些缓存不上传到作者服务器。

联系方式

通过扩展内「留言反馈」，或 Edge 附加组件商店该条目的反馈渠道联系作者。
